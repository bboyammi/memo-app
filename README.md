# MEMO FOR NAMJUN 💙

좋아하는 사진을 올려 두고, 메모와 할 일을 적는 작은 컴퓨터 메모장이에요.
사진과 배경색을 내 취향에 맞게 바꿀 수 있어요. **무료로 내려받아 설치하면 됩니다. GitHub 로그인은 필요 없어요.**

## 1️⃣ 내 컴퓨터에 맞는 파일을 눌러 주세요

### 🍎 맥북·아이맥을 쓰고 있다면

**👉 [맥용 메모장 다운로드](https://github.com/Kim-hae-sol/memo-app/releases/download/v0.1.1/Namjun.Memo-0.1.1-arm64.dmg)**

M1·M2·M3·M4 등 **Apple 칩이 들어간 Mac용**이에요. Intel Mac에서는 사용할 수 없어요.
어떤 Mac인지 모르겠다면 화면 왼쪽 위 ** → 이 Mac에 관하여**를 눌러 확인해 주세요. ‘칩’에 Apple M으로 시작하는 이름이 있으면 이 파일을 받으면 돼요.

### 🪟 윈도우 노트북·컴퓨터를 쓰고 있다면

**👉 [윈도우용 메모장 다운로드](https://github.com/Kim-hae-sol/memo-app/releases/download/v0.1.1/Namjun.Memo.Setup.0.1.1.exe)**

일반적인 **Intel·AMD 64비트 윈도우 PC용**이에요.
아직 Windows 컴퓨터에서 실제 설치·실행을 확인하지 못한 테스트 버전이에요. 설치나 실행 중 문제가 생기면 알려 주세요.

> 위의 다운로드 글씨를 누르면 설치 파일을 받게 돼요. ‘Source code’나 다른 파일은 받지 않아도 됩니다.

## 2️⃣ 다운로드한 파일을 설치해 주세요

### 🍎 Mac 설치 방법

1. **Finder → 다운로드** 폴더를 열어 주세요.
2. 방금 받은 **Namjun.Memo-0.1.1-arm64.dmg** 파일을 더블클릭하세요.
3. 창이 열리면 왼쪽 **Namjun Memo 아이콘**을 마우스로 꾹 누르세요.
4. 누른 채로 오른쪽 파란색 **Applications 폴더**까지 끌어간 뒤 놓으세요.
5. 복사가 끝나면 **Applications 폴더를 더블클릭**하세요.
6. 그 안에서 **Namjun Memo를 찾아 더블클릭**하면 메모장이 열려요!

이미 메모장이 설치돼 있다면 먼저 기존 앱을 X로 종료해 주세요. 복사 중 같은 앱이 있다는 안내가 나오면 **‘대치’**를 누르면 됩니다. 기존 메모와 설정은 유지돼요.

### 🪟 Windows 설치 방법

1. **파일 탐색기 → 다운로드** 폴더를 열어 주세요.
2. 방금 받은 **Namjun.Memo.Setup.0.1.1.exe** 파일을 더블클릭하세요.
3. 설치가 진행되는 동안 잠시 기다려 주세요.
4. 설치 후 앱이 바로 열리지 않으면 **시작 메뉴에서 Namjun Memo를 검색해 실행**하세요.

다음부터는 설치 파일을 다시 열 필요 없어요. 설치된 **Namjun Memo 앱**을 열면 됩니다.

## ⚠️ 설치할 때 경고가 나오나요?

현재는 **0.1.1 테스트 버전**이에요. Apple·Microsoft의 개발자 인증을 받지 않아 ‘개발자를 확인할 수 없음’ 같은 보안 경고가 표시될 수 있어요.

Mac에서 ‘개발자를 확인할 수 없음’으로 실행이 막힌 경우, 이 페이지에서 받은 파일이 맞는지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용할 수 있어요. [Apple 공식 설명 보기](https://support.apple.com/ko-kr/102445)

다른 오류가 나오거나 어떻게 해야 할지 모르겠다면 **경고 문구를 알려 주세요.** ‘앱이 손상됨’이나 악성 소프트웨어 경고는 같은 경우로 취급하지 말고 확인이 필요해요.

## 3️⃣ 메모장은 이렇게 사용해요

| 하고 싶은 일 | 이렇게 해 주세요 |
| --- | --- |
| 메모 쓰기 | **메모**를 누르고 큰 색상 영역에 글을 입력하세요. |
| 할 일 추가하기 | **To do list → + 할 일 추가하기**를 누르세요. |
| 끝낸 일 표시하기 | 할 일 옆 **네모 칸**을 누르세요. |
| 할 일 삭제하기 | 그 항목 오른쪽의 **×**를 누르세요. |
| 날짜 보기 | **캘린더**를 누르세요. 달력에 마우스를 올리면 달 이동 버튼이 보여요. |
| 창을 다른 곳으로 옮기기 | **사진 옆, 맨 위 색상 바의 빈 공간**을 꾹 누른 채 끌어 주세요. |
| 작게 접어 두기 | 맨 위 **−**를 누르세요. 펼치기 아이콘을 누르면 원래 크기로 돌아와요. |
| 내 사진으로 바꾸기 | **♥ → 사진 변경**에서 사진을 고르세요. PNG·JPG·GIF를 최대 50MB까지 넣을 수 있어요. |
| 색상 바꾸기 | **♥ → 사진 테마 추천**에서 고르거나 **직접 색상 설정**을 사용하세요. |
| 다른 창 위에 띄워 두기 | **♥ → 항상 위에 표시**를 켜세요. |
| 메모장 종료하기 | 맨 위 오른쪽 **X**를 누르세요. |

**따로 저장 버튼을 누를 필요 없어요.** 메모·할 일·설정은 사용 중인 컴퓨터에 자동으로 저장돼요. 같은 컴퓨터에서 앱을 다시 열면 그대로 이어서 사용할 수 있어요. 다른 컴퓨터로 자동 동기화되는 기능은 없어요.
