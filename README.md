# MEMO FOR NAMJUN

사진과 색상을 바꿀 수 있는 플로팅 메모장입니다. 캘린더·메모·할 일·접기 모드를 제공합니다.

## 다운로드 — 0.1.1 테스트 버전

| 컴퓨터 | 다운로드 |
| --- | --- |
| Mac: Apple Silicon (M1·M2·M3·M4 등) | [맥용 설치 파일](https://github.com/Kim-hae-sol/memo-app/releases/download/v0.1.1/Namjun%20Memo-0.1.1-arm64.dmg) |
| Windows: Intel/AMD 64비트 | [윈도우용 설치 파일](https://github.com/Kim-hae-sol/memo-app/releases/download/v0.1.1/Namjun%20Memo%20Setup%200.1.1.exe) |

Intel Mac용은 제공하지 않습니다. **Windows 실제 기기에서의 설치·실행 검증은 아직 완료되지 않았습니다.**

## 설치

**Mac:** DMG 열기 → Namjun Memo를 Applications 폴더로 드래그 → 응용 프로그램 폴더에서 실행하세요. 기존 앱을 먼저 종료하고, 같은 앱이 있으면 대치하세요.

**Windows:** EXE 파일을 더블클릭해 설치하고 시작 메뉴에서 Namjun Memo를 실행하세요.

개발자 인증 전 테스트 버전이므로 보안 경고가 표시될 수 있습니다. Mac에서 차단되면 [Apple 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

## 사용

- 헤더를 드래그하면 창이 이동합니다.
- 탭으로 캘린더·메모·할 일을 전환합니다.
- − 버튼은 접기·펼치기, X 버튼은 종료입니다.
- 하트 설정에서 사진·테마·항상 위 표시를 변경합니다.
- PNG·JPG·GIF(최대 50MB)를 지원합니다.
- 메모와 할 일은 사용하는 컴퓨터에 자동저장됩니다.

릴리스의 SHA256SUMS.txt로 설치 파일의 해시를 확인할 수 있습니다.
