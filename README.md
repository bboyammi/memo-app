# MEMO FOR NAMJUN 💙

좋아하는 사진으로 꾸미는 작은 데스크톱 메모장이에요.

메모·할 일·캘린더를 한곳에서 쓰고, 사진에 어울리는 테마색도 고를 수 있어요. 무료이며 GitHub 로그인은 필요하지 않아요.

## 💻 최신 버전 다운로드 (v0.1.6)

### 🍎 Mac용

[**Mac용 다운로드 (.dmg)**](https://github.com/bboyammi/memo-app/releases/download/v0.1.6/Namjun-Memo-0.1.6-arm64.dmg)

Apple Silicon(M1·M2·M3·M4 등) Mac용입니다.

### 🪟 Windows용

[**Windows용 다운로드 (.exe)**](https://github.com/bboyammi/memo-app/releases/download/v0.1.6/Namjun-Memo-Setup-0.1.6.exe)

Intel·AMD 64비트 Windows PC용입니다.

> 설치 파일은 위의 링크만 누르면 됩니다. `Source code`, `.yml`, `.blockmap` 파일은 직접 받을 필요가 없어요.

## 📖 설치 방법

### 🍎 Mac

1. 위의 Mac용 DMG 파일을 다운로드해 더블클릭하세요.
2. Namjun Memo 아이콘을 Applications 폴더로 끌어다 놓으세요.
3. Applications에서 Namjun Memo를 실행하세요.

### 🪟 Windows

1. 위의 Windows용 EXE 파일을 다운로드하세요.
2. 파일을 더블클릭하고 설치를 진행하세요.
3. 시작 메뉴에서 Namjun Memo를 실행하세요.

## ✨ 주요 기능

- 메모 작성 및 placeholder
- 할 일 추가·체크·삭제
- 현재 날짜를 보여주는 캘린더
- PNG·JPG·GIF 사진 변경
- 사진 기반 테마 추천 및 직접 색상 설정
- 항상 위에 표시
- 메모·할 일·설정 자동저장
- 창 크기 조절 및 마지막 크기 복원
- 접기(컴팩트 모드)와 다시 펼치기
- Mac·Windows 자동 업데이트 안내

## 🔄 자동 업데이트

v0.1.2 이상을 설치하면 새 버전이 나왔을 때 앱이 자동으로 확인하고, 다운로드와 재시작을 안내합니다.

v0.1.1 사용자는 먼저 위의 v0.1.6 설치 파일을 한 번 직접 설치해 주세요.

## ⚠️ 보안 안내

개발자 인증이 없어 Mac에서 처음 실행할 때 보안 경고가 나타날 수 있습니다.

Mac에서 열리지 않으면:

1. **완료**를 누르세요.
2. Finder의 **응용 프로그램**에서 Namjun Memo를 마우스 오른쪽 클릭하세요.
3. **열기 → 열기**를 선택하세요.

그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택하세요.

Windows용 기능은 실제 Windows 기기에서 직접 검증하지 못했으므로, 문제가 생기면 알려 주세요.
